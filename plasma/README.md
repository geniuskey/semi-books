# PlasmaBook — 인터랙티브 플라즈마공학 교과서

전자가 기체를 깨우는 기술. 식각·증착 공정의 엔진인 저온 플라즈마를 물리에서 소스·진단·모델·공정까지 깊이 다루는 편으로, 공대 학부생과 신입 공정·장비 엔지니어를 위한 한국어 학습 사이트입니다.
18개 챕터, 140여 개의 시뮬레이터, 3D 소스·진단 모델(three.js)로 구성되며, 가상 기준 장비 PL-300의 압력·전력·주파수·바이어스 손잡이로 직접 플라즈마를 켜 봅니다.

배포 주소: https://semi.euiyun.com/plasma/

## 실행
원본은 빌드 없이 동작하는 정적 사이트입니다. 저장소 루트에서 실행하세요.

```bash
python3 -m http.server 8000   # → http://localhost:8000/plasma/
```
배포할 때는 저장소 루트의 `npm run build`가 head 메타데이터와 KaTeX 수식을 미리 렌더링합니다. three.js와 폰트는 CDN에서 불러오므로 인터넷 연결이 필요합니다.

## 구성
| 장 | 파일 | 내용 |
|---|---|---|
| 01 | chapters/overview.html | 플라즈마의 지도 — 물질의 네 번째 상태. 전자 온도와 밀도로 그린 플라즈마 지도, 반도체 공정이 플라즈마를 쓰는 이유, 플라즈마 장비 한 대의 구조와 이 책의 길. |
| 02 | chapters/scales.html | 플라즈마의 척도: 데바이·주파수·준중성 — 전하가 서로를 가리는 데바이 길이, 전자가 출렁이는 플라즈마 주파수, 준중성과 플라즈마 파라미터. 무엇이 플라즈마인지 정하는 세 잣대. |
| 03 | chapters/collisions.html | 충돌과 반응 속도 — 단면적과 평균 자유 행로, 탄성·여기·이온화·부착 충돌, 반응 속도 계수 k(Tₑ), 전자-이온 쌍 하나를 만드는 데 드는 에너지. |
| 04 | chapters/eedf.html | 전자 에너지 분포 — 맥스웰과 드루이베스테인, 볼츠만 방정식과 E/N, 꼬리가 반응 속도를 정하는 이유, 두 온도 분포와 분포를 바꾸는 손잡이. |
| 05 | chapters/breakdown.html | 방전 개시와 직류 글로 — 전자 사태와 타운센드 계수, 파셴 곡선, 암흑 방전에서 글로와 아크까지의 전류-전압 곡선, 음극 강하와 직류 글로의 구조. |
| 06 | chapters/transport.html | 수송: 이동도·확산·양극성 — 전기장 속 표류와 확산, 아인슈타인 관계, 전자와 이온을 함께 묶는 양극성 확산, 밀도 프로파일과 확산 길이, 자기장 속 수송. |
| 07 | chapters/sheath.html | 시스와 보옴 기준 — 벽 앞에 생기는 양전하층. 부유 전위, 보옴 속도와 예비 시스, 차일드 법칙, 충돌 시스, RF 시스의 정류와 자기 바이어스. |
| 08 | chapters/global.html | 전역 모델: 입자·전력 균형 — 입자 균형이 전자 온도를, 전력 균형이 밀도를 정한다. 압력·크기·전력 스케일링, 전기 음성 플라즈마와 음이온, 혼합 기체. |
| 09 | chapters/ccp.html | 용량 결합 플라즈마 — 평행판 사이의 RF 방전. 저항·확률 가열, α·γ 모드, 이중 주파수로 밀도와 이온 에너지 나누기, VHF 정상파와 균일도. |
| 10 | chapters/icp.html | 유도 결합 플라즈마와 고밀도 소스 — 코일이 만드는 유도 전기장과 표피 깊이, 변압기 모델, E-H 모드 전환과 히스테리시스, 전력 전달 효율, ECR·헬리콘·마이크로파. |
| 11 | chapters/rf.html | RF 전력 전달과 임피던스 정합 — 50 Ω 전송선과 반사 계수, 스미스 차트, L형 정합 회로, 플라즈마 임피던스, 자동 정합과 주파수 튜닝, 고조파와 아크. |
| 12 | chapters/pulsed.html | 펄스 플라즈마와 맞춤 파형 — 켰다 끄는 플라즈마. 잔광에서의 전자 냉각과 밀도 감쇠, 듀티와 주파수, 동기·비동기 펄스, 맞춤 바이어스 파형과 좁은 이온 에너지. |
| 13 | chapters/chemistry.html | 플라즈마 화학과 래디컬 — 전자 충돌 해리와 반응 네트워크, 체류 시간과 래디컬 밀도, 벽 재결합, CF₄/O₂·Cl₂·SiH₄·NF₃ 화학과 원격 플라즈마. |
| 14 | chapters/surface.html | 플라즈마-표면 상호작용과 손상 — 이온 충격과 스퍼터링, 이온-중성 시너지, 2차 전자 방출, 웨이퍼 가열, 챔버 벽 시즈닝, 대전 손상과 UV 손상. |
| 15 | chapters/diagnostics.html | 플라즈마 진단 — 랭뮤어 탐침 I-V로 Tₑ·nₑ·EEDF 읽기, 발광 분광과 액티노메트리, V-I 탐침, 헤어핀 탐침·마이크로파 간섭계, 지연 전위 분석기. |
| 16 | chapters/modeling.html | 플라즈마 모델링: 유체·PIC·하이브리드 — 전역·유체·입자(PIC/MCC)·하이브리드 모델의 차이, 표류-확산 풀이와 1D PIC 실습, 무엇을 언제 쓰는가. |
| 17 | chapters/applications.html | 반도체 공정의 플라즈마 — 식각·PECVD·스퍼터·애싱·챔버 세정·플라즈마 도핑의 소스와 조건, 공정 창, 챔버 매칭과 고장 감지, 플라즈마 비용. |
| 18 | chapters/glossary.html | 용어집 & 종합 퀴즈 — 플라즈마공학 핵심 용어를 검색하고, 종합 퀴즈로 실력을 점검하자. |

공통 코드: `css/style.css`(디자인 토큰, 라이트/다크), `js/common.js`(내비게이션, 캔버스·차트·3D 헬퍼, 전역 `PB`).
챕터 작성 규칙은 [CONTRIBUTING.md](CONTRIBUTING.md)를 참고하세요.

시뮬레이터의 수치는 교육용 근사 모델입니다. 실제 수치는 공개 자료 기준의 대략값이며 특정 회사의 내부 값이 아닙니다.

## 용어집과 본문 뜻풀이

용어 정의는 `js/glossary-data.js`의 `window.BOOK_GLOSSARY`에 저장합니다. 용어집과 본문 뜻풀이가 같은 데이터를 사용하며, 본문에서 용어에 마우스를 올리거나 키보드로 포커스하거나 모바일에서 탭하면 정의를 확인할 수 있습니다. 공통 동작과 스타일은 `js/glossary-tooltips.js`, `css/glossary-tooltips.css`입니다. 데이터 형식은 시리즈 공통 v1이며, 각 항목은 `ko`(이름), `en`(영문명), `abbr`(약어), `def`(정의), `chapters`(관련 장 목록)를 갖습니다.
