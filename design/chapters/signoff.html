Chapter 10

물리 검증: DRC · LVS

타이밍과 전력을 통과한 레이아웃도 아직 공장에 보낼 수 없다. 두 가지 질문이 남았다. 이 사각형들을 실제로 만들 수 있는가, 그리고 만든 것이 의도한 회로인가. 첫째는 설계 규칙 검사(DRC), 둘째는 레이아웃 대 회로도 비교(LVS)가 답한다. 파운드리는 둘 다 깨끗한 GDS만 받는다. 이 장에서는 규칙 하나하나가 ProcessBook의 어떤 공정 한계에서 나왔는지 거슬러 올라가 보고, 4장의 셀 위에서 검증 엔진을 직접 돌려 본다.

  • 설계 규칙의 종류(폭·간격·둘러싸기·연장·밀도·안테나)와 각각의 공정적 근거를 설명한다.
  • DRC가 다각형 연산(크기 조절, AND/NOT, 거리 측정)으로 규칙을 검사하는 원리를 안다.
  • 레이아웃에서 소자·넷을 추출하고 회로도와 그래프 동형으로 비교하는 LVS의 흐름을 따라간다.
  • LVS 오류 유형(단락·개방·소자 불일치·핀 바뀜)을 구분하고 원인을 찾는다.
  • 안테나 비율과 밀도 규칙을 계산한다.

규칙은 공정에서 온다

설계 규칙 매뉴얼(DRM, Design Rule Manual)은 수백 쪽, 첨단 공정에서는 규칙이 수천 개다. 그러나 모든 규칙은 몇 가지 공정 한계로 거슬러 올라간다. 설계자는 공정을 직접 보지 못하므로, 파운드리는 수율을 지키는 데 필요한 최소한의 기하 조건을 규칙으로 번역해 넘긴다. 규칙을 지키면 “충분히 높은 확률로” 만들어진다는 계약이다.

DRC는 어떻게 검사하나

DRC 도구는 레이아웃을 레이어별 다각형 집합으로 읽고, 불 연산(AND, OR, NOT), 크기 조절(sizing: 경계를 바깥·안쪽으로 밀기), 거리 측정(같은·다른 다각형 변 사이)을 조합한 규칙 덱(rule deck)을 실행한다. 예를 들면 다음과 같다.

GATE   = PO AND OD                          // 트랜지스터 채널
SD     = OD NOT PO                          // 소스·드레인
PO.W.1 { INT PO < 0.050 }                   // 내부 거리(폭) < 50 nm
PO.S.1 { EXT PO < 0.080 }                   // 외부 거리(간격) < 80 nm
CO.EN.1 { ENC CO (OD OR PO) < 0.015 }      // 둘러싸기
PO.EX.1 { (GATE SIZE BY 0.060 ALONG PO) NOT PO }   // 엔드캡 부족 영역
IMP.X.1 { NP AND PP }                       // 겹침 금지 → 면적 있으면 오류

대규모 칩은 다각형이 수백억 개라, 도구는 계층 구조(같은 셀은 한 번만 검사)와 수천 개 CPU 병렬화로 몇 시간 안에 끝낸다. 위반은 대부분 셀 사이·배선에서 나오며, 배선기가 남긴 규칙 위반(DRV)을 사인오프 DRC 결과와 맞춰 고치는 반복이 테이프아웃 직전의 주된 일이다.

규칙을 지켜도 안전하지 않을 때

최소 규칙만 겹겹이 쓴 곳은 공정 편차가 조금만 커져도 먼저 실패한다. 그래서 DRM에는 수율 권장 규칙(recommended rules)이 있고, 노광 시뮬레이션으로 위험한 모양을 찾는 리소 핫스팟 검사(LFD, 11장), 결함 밀도와 임계 면적으로 수율을 추정하는 CAA(Critical Area Analysis)를 함께 돌린다. DFM(Design for Manufacturability)이라 부르는 영역이다.

LVS: 레이아웃은 회로도와 같은가

LVS는 두 단계다. 먼저 추출: 레이어 연산으로 소자를 인식하고(GATE = PO AND OD, NP/PP로 종류), 도전층의 연결(CO, V1로 층 사이)을 따라 넷을 만든다. 4장 추출 시뮬레이터가 이 과정을 보였다. 다음은 비교: 추출한 넷리스트와 회로도 넷리스트를 그래프로 보고 동형인지 확인한다. 핀 이름이 붙은 넷(VDD, VSS, A, Y…)을 닻으로 삼고, 소자 종류·연결 수를 이용한 꼬리표 정제(partition refinement)로 나머지 노드를 짝지어 나간다. 같은 L·연결의 병렬 트랜지스터는 하나로 합치고(W를 더함), 직렬 소자의 순서 교환처럼 전기적으로 같은 변형은 허용한다.

LVS 디버깅: 무엇이 틀렸나

대상은 4장의 NAND2_X1이다. 해볼 것: ① 주입 바뀜: PMOS 위 PP를 NP로 잘못 그렸다. LVS는 PMOS가 사라지고 NMOS가 넷이 된 소자 종류 불일치로, DRC는 N-웰 안에 NMOS 확산이 생긴 웰 간격 위반으로 잡는다. ② 입력 바뀜: 핀 라벨 A와 B를 바꿔 붙였다. NAND는 A·B가 대칭이라 논리는 같지만, NMOS 직렬 순서가 바뀌어 회로도와 다르다. 실무 LVS는 이런 교환을 허용할지 옵션으로 정한다(여기서는 엄격 비교). ③ 단락·개방은 넷 이름 충돌·분리로 보고된다. ④ 여분 소자: NMOS 직렬 노드 위로 폴리 조각이 지나가 트랜지스터가 하나 더 생겼다. DRC는 폴리 최소 폭(40 nm < 50 nm)과 간격 위반을 지적하지만, LVS는 “소자가 하나 많다”는 결과로 회로가 바뀌었음을 알려 준다.

안테나 규칙

배선층을 플라즈마로 식각하는 동안(ProcessBook 6장) 금속 표면에 이온·전자가 쌓인다. 그 금속이 아직 트랜지스터 게이트에만 연결되어 있고 확산(방전 경로)과는 위층에서야 연결될 예정이라면, 모인 전하는 얇은 게이트 절연막을 통해 흐르며 절연막을 손상시킨다(문턱 전압 이동, 신뢰성 저하). 금속이 넓을수록 전하를 많이 모으므로 규칙은 비율로 정한다.

$$\text{AR} = \frac{\text{게이트에 연결된 (아직 확산에 닿지 않은) 금속 면적}}{\text{게이트 면적}} \;\le\; \text{AR}_{\max}\ (\text{예: } 400)$$
층별로 따로 계산하는 방식과 누적하는 방식이 있다. 위반을 고치는 방법: ① 배선을 끊고 위층으로 점프(jumper)해 긴 금속이 마지막에 연결되게, ② 게이트 가까이에 역방향 다이오드(안테나 다이오드)를 달아 방전 경로 확보, ③ 버퍼를 넣어 긴 배선을 다른 게이트에 맡김.

밀도 규칙

CMP는 패턴 밀도에 따라 깎이는 양이 달라(ProcessBook 10장), 금속이 너무 성기거나 빽빽한 영역은 두께가 크게 달라진다. 그래서 DRC는 칩을 일정 크기의 창(예: 50 × 50 µm)으로 훑으며 창마다 층별 밀도가 범위(예: 20~80%) 안인지 본다. 모자란 곳은 전기적으로 떠 있는 더미 필로 채우고, 넘치는 넓은 금속에는 구멍(슬롯)을 뚫는다.

숨겨진 위반을 60초 안에 찾는 15장 DRC 위반 찾기, 그리고 직접 그려 통과시키는 13장 실험실으로 이어 가자.

핵심 정리

  1. 설계 규칙은 해상도·오버레이·선 끝 후퇴·식각·CMP·대전 같은 공정 한계를 기하 조건으로 번역한 계약이다.
  2. DRC는 불 연산·크기 조절·거리 측정을 조합한 규칙 덱으로 다각형을 검사한다.
  3. LVS는 레이아웃에서 소자·넷을 추출해 회로도와 그래프 동형인지 비교한다. 병렬 소자는 합친다.
  4. DRC 통과가 회로의 정확성을, LVS 통과가 제조 가능성을 보장하지 않는다. 둘 다 필요하다.
  5. 안테나 비율은 점프·다이오드로, 밀도 위반은 더미 필·슬롯으로 고친다.

확인 퀴즈

콘택의 활성 영역 둘러싸기 규칙이 주로 대비하는 공정 현상은?

두 층을 따로 찍으므로 수 nm 어긋날 수 있다. 둘러싸기 여유가 없으면 콘택이 STI·웰에 닿아 누설·단락이 생긴다.

LVS에서 같은 게이트·소스·드레인을 공유하는 NMOS 두 개(각 W = 300 nm)는 어떻게 비교되는가?

핑거 여러 개로 그린 큰 트랜지스터가 대표적인 예다. 회로도의 W = 600 nm 소자 하나와 일치한다.

안테나 위반을 고치는 방법으로 알맞지 않은 것은?

금속 면적이 늘면 모으는 전하가 늘어 비율이 오히려 커진다.

DRC는 깨끗하지만 LVS가 실패하는 예는?

규칙상 문제없는 모양이어도 회로가 달라질 수 있다. 나머지는 모두 DRC 위반이다.
