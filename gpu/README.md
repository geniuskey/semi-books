# GPUBook — 인터랙티브 GPU 칩 설계 교과서

GPU 칩은 왜 이렇게 생겼나. 데이터센터 GPU를 프로그래밍 대상이 아니라 **칩**으로 다루는 편입니다. CPU와 다른 면적 배분, 지연을 숨기는 처리량 기계, SM과 워프 스케줄러·레지스터 파일, 연산 유닛과 수 표현, 텐서 코어와 시스톨릭 배열, 온칩 SRAM과 루프라인, HBM과 메모리 대역폭, 온칩 네트워크, 다이 크기·수율·칩렛, 2.5D·3D 패키징, 전력 공급과 DVFS, 발열과 냉각, 칩간 링크와 스케일업, AI·그래픽 워크로드와 산업까지, **면적·대역폭·전력·원가**라는 네 가지 예산이 설계를 어떻게 정하는지 계산합니다. 공대 학부생과 신입 반도체·회로·시스템 엔지니어를 위한 한국어 학습 사이트입니다.
17개 챕터, 131개의 시뮬레이터, 3D 패키지·SM·HBM 모델(three.js)로 구성되며, 가상 기준 칩 GX-1(4 nm급 780 mm² 다이, 활성 SM 144개, BF16 약 944 TFLOPS, HBM 6스택 144 GB·7.37 TB/s, 실리콘 인터포저, 1,000 W)의 숫자로 직접 계산해 봅니다.

배포 주소: https://semi.euiyun.com/gpu/

## 실행
원본은 빌드 없이 동작하는 정적 사이트입니다. 저장소 루트에서 실행하세요.

```bash
python3 -m http.server 8000   # → http://localhost:8000/gpu/
```
배포할 때는 저장소 루트의 `npm run build`가 head 메타데이터와 KaTeX 수식을 미리 렌더링합니다. three.js와 폰트는 CDN에서 불러오므로 인터넷 연결이 필요합니다.

## 구성
| 장 | 파일 | 내용 |
|---|---|---|
| 01 | chapters/overview.html | GPU라는 칩의 지도 — CPU와 GPU는 같은 실리콘 면적을 어떻게 다르게 쓰는가. 지연 대 처리량, 그래픽에서 AI로, 가상 기준 칩 GX-1을 다이·HBM·인터포저·기판까지 3D로 해부한다. |
| 02 | chapters/throughput.html | 처리량 기계: 지연을 숨기는 법 — 리틀의 법칙과 동시에 떠 있어야 할 일의 양, 하드웨어 멀티스레딩, SIMD와 SIMT, 암달의 법칙. 왜 수천 개의 스레드가 필요한가. |
| 03 | chapters/sm.html | SM 해부: 워프와 레지스터 파일 — 서브파티션과 워프 스케줄러, 스코어보드와 발행, 뱅크로 나뉜 레지스터 파일, 점유율, 분기 발산과 재수렴. SM 한 개의 면적 예산. |
| 04 | chapters/alu.html | 연산 유닛과 수 표현 — FP32·FP16·BF16·FP8·INT8의 비트 배치와 곱셈기 면적·에너지, FMA 회로, 특수 함수 유닛. 정밀도를 낮추면 같은 면적에서 몇 배를 더 계산하는가. |
| 05 | chapters/tensor.html | 텐서 코어와 행렬 엔진 — 행렬곱이 데이터 재사용을 만드는 이유, 내적 트리와 시스톨릭 배열, 텐서 코어의 입출력 대역폭, 구조적 희소성, 마이크로스케일링 포맷, NPU와의 비교. |
| 06 | chapters/onchip.html | 온칩 메모리: 레지스터에서 L2까지 — SRAM 비트셀과 면적, 레지스터·공유 메모리·L1·L2의 용량과 대역폭, 접근 병합과 뱅크 충돌, 캐시 적중률, 거리에 비례하는 데이터 이동 에너지. |
| 07 | chapters/roofline.html | 루프라인과 데이터 재사용 — 산술 강도와 리지 포인트, 타일링으로 재사용을 늘리는 법, GEMM·어텐션·원소별 연산의 위치. 연산량과 대역폭의 비율이 칩 설계를 정한다. |
| 08 | chapters/hbm.html | HBM과 메모리 대역폭 — 대역폭 = 핀 수 × 핀 속도, GDDR과 HBM, TSV로 쌓은 DRAM 스택과 베이스 다이, 채널과 뱅크, 비트당 에너지, 용량과 대역폭의 줄다리기. |
| 09 | chapters/noc.html | 온칩 네트워크와 L2 — SM과 L2 슬라이스를 잇는 크로스바와 메시, 배선 RC와 리피터, 클럭 분배와 도메인, 다이 평면 배치. 데이터가 칩을 가로지르는 비용. |
| 10 | chapters/die.html | 다이 크기·수율·칩렛 — 레티클 한계, 웨이퍼당 다이 수, 결함 밀도와 수율 모델, SM 하베스팅, 양품 다이당 원가, 칩렛으로 나누는 이유와 다이 간 연결의 대가. |
| 11 | chapters/package.html | 2.5D·3D 패키징 — 실리콘 인터포저와 RDL·브리지, 마이크로범프 피치와 배선 밀도, 인터포저 크기와 휨, HBM을 다이 옆에 두는 이유, 하이브리드 본딩과 3D 적층. |
| 12 | chapters/power.html | 전력 공급과 DVFS — 동적 전력 CV²f와 누설, 전압·주파수 곡선과 전력 상한, 1000 A를 공급하는 전력망(PDN), IR 드롭과 디커플링, 전압 레귤레이터의 위치와 후면 전력. |
| 13 | chapters/thermal.html | 발열과 냉각 — 다이에서 냉각수까지의 열저항, 열밀도와 핫스팟, 열 스로틀링, 냉각판·액침 냉각, 랙 전력과 데이터센터. 온도가 성능 상한이 되는 과정. |
| 14 | chapters/scale.html | 칩 사이의 링크와 스케일업 — SerDes와 PAM4, 채널 손실과 이퀄라이저, 칩간 링크와 스위치, 올리듀스 시간 모델, 구리와 광, 공동 패키징 광학. 여러 GPU를 한 대처럼. |
| 15 | chapters/workloads.html | 워크로드가 칩을 만든다 — LLM의 학습·프리필·디코드가 각각 어디서 막히는가, KV 캐시와 배치, 그래픽 파이프라인과 고정 기능 유닛, 면적 배분 설계 실험. |
| 16 | chapters/roadmap.html | GPU 산업과 다음 세대 — 세대별 연산·메모리·전력 추세, 파운드리·HBM·첨단 패키징 공급망, GPU와 맞춤형 가속기, 원가 구조, 후면 전력·3D 적층·광 연결의 다음 단계. |
| 17 | chapters/glossary.html | 용어집 & 종합 퀴즈 — GPU 칩 설계 용어를 검색하고, 종합 퀴즈로 실력을 점검하자. |

공통 파일: `css/style.css`, `js/common.js`(전역 객체 `GP`, DeviceBook v2 그림·시뮬레이터 키트에서 이식), `js/glossary-data.js`(용어집과 본문 툴팁이 함께 쓰는 용어 원본), `js/glossary-tooltips.js`. 장마다 시뮬레이터 모델을 검사하는 회귀 스크립트가 `scripts/<장>-sims.cjs`에 있고 루트 `npm test`가 모두 돌립니다. 한 장의 수식만 빠르게 확인할 때는 `node gpu/tools/katex-check.mjs gpu/chapters/<장>.html`. 집필 규칙과 GX-1 수치는 [CONTRIBUTING.md](CONTRIBUTING.md)에 있습니다.
