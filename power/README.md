# PowerBook — 인터랙티브 전력 반도체 교과서

전기를 다루는 반도체. 전기차 인버터, 충전기, 데이터센터 전원, 태양광 인버터 안에서 초당 수만 번 켜고 꺼지는 전력 반도체를 재료·항복 물리에서 소자, 스위칭과 구동, 변환 회로, 열·패키징·신뢰성, 응용까지 깊이 다루는 편으로, 공대 학부생과 신입 소자·회로·시스템 엔지니어를 위한 한국어 학습 사이트입니다.
18개 챕터, 140개의 시뮬레이터, 3D 소자·모듈 모델(three.js)로 구성되며, 가상 기준 플랫폼 PW-800(800 V 전기차 트랙션 인버터, 온보드 충전기, GaN 충전기, 48 V 서버 전원)의 숫자로 직접 계산해 봅니다.

배포 주소: https://semi.euiyun.com/power/

## 실행
원본은 빌드 없이 동작하는 정적 사이트입니다. 저장소 루트에서 실행하세요.

```bash
python3 -m http.server 8000   # → http://localhost:8000/power/
```
배포할 때는 저장소 루트의 `npm run build`가 head 메타데이터와 KaTeX 수식을 미리 렌더링합니다. three.js와 폰트는 CDN에서 불러오므로 인터넷 연결이 필요합니다.

## 구성
| 장 | 파일 | 내용 |
|---|---|---|
| 01 | chapters/overview.html | 전력 반도체의 지도 — 전기를 바꾸는 스위치. 전력 변환이 무엇이고 왜 반도체 스위치가 필요한지, 전압·전류·주파수로 그린 응용 지도, Si·SiC·GaN의 자리, 인버터 한 대의 해부와 이 책의 길. |
| 02 | chapters/materials.html | 재료: 밴드갭과 임계 전계 — 왜 넓은 밴드갭인가. 임계 전계·이동도·유전율·열전도의 비교, 바리가 성능 지수와 단극 한계, 4H-SiC·GaN·Ga₂O₃·다이아몬드, 기판과 결함. |
| 03 | chapters/breakdown.html | 항복과 드리프트층 — 충돌 이온화와 애벌런치, 이온화 적분, 평행 평면 접합의 항복 전압, 비펀치스루·펀치스루 드리프트층 최적화, 온저항과 항복 전압의 트레이드오프. |
| 04 | chapters/termination.html | 에지 종단과 표면 전계 — 칩 가장자리에서 항복이 먼저 오는 이유. 접합 곡률, 필드 플레이트, 플로팅 가드 링, 접합 종단 확장(JTE), 표면 전하와 패시베이션, 2차원 전계 풀이. |
| 05 | chapters/diodes.html | 전력 다이오드: PiN과 쇼트키 — 전도도 변조와 순방향 강하, 저장 전하와 역회복(Qrr, 소프트·스냅), 수명 제어, 쇼트키 장벽과 누설, SiC JBS·MPS 다이오드. |
| 06 | chapters/mosfet.html | 전력 MOSFET과 슈퍼정션 — 수직 DMOS와 트렌치 MOSFET, 온저항 성분 분해, 커패시턴스와 게이트 전하, 슈퍼정션의 전하 균형, 바디 다이오드와 애벌런치 내량. |
| 07 | chapters/igbt.html | IGBT와 사이리스터 — MOSFET 입력과 바이폴라 출력. 전도도 변조와 포화 전압, 꼬리 전류와 턴오프 손실, 래치업, 필드 스톱·트렌치·RC-IGBT, 사이리스터·GTO·IGCT. |
| 08 | chapters/sic.html | SiC MOSFET — 4H-SiC MOSFET의 구조와 온저항, SiO₂/SiC 계면 트랩과 채널 이동도, 문턱 전압 이동과 게이트 산화막 신뢰성, 바디 다이오드 열화, 단락 내량, 웨이퍼와 결함. |
| 09 | chapters/gan.html | GaN HEMT — 분극이 만든 2차원 전자 가스, 공핍형과 증강형(p-GaN 게이트·캐스코드), 전류 붕괴와 동적 온저항, GaN-on-Si 에피, 수직 GaN과 집적. |
| 10 | chapters/switching.html | 스위칭 과도와 손실 — 이중 펄스 시험으로 보는 턴온·턴오프 파형, 밀러 플래토, dv/dt·di/dt, 기생 인덕턴스와 전압 오버슈트, 스위칭 에너지 Eon·Eoff·Err, 소프트 스위칭. |
| 11 | chapters/gatedrive.html | 게이트 구동과 보호 — 게이트 저항과 구동 전압, 음 바이어스와 밀러 클램프, 절연과 공통 모드 내성, 부트스트랩, 단락 감지(DESAT)와 소프트 턴오프, 능동 게이트 구동. |
| 12 | chapters/converters.html | DC-DC 변환과 PFC — 벅·부스트의 전압 변환비와 리플, CCM·DCM, 동기 정류, 하드·소프트 스위칭, LLC 공진 컨버터, 역률 보정과 토템폴 PFC, 효율 곡선 읽기. |
| 13 | chapters/inverter.html | 인버터와 PWM — 하프 브리지에서 3상 인버터까지. 사인파 PWM과 공간 벡터 PWM, 데드 타임, 전류 리플과 고조파, 전도·스위칭 손실 계산, 모터 구동과 회생. |
| 14 | chapters/thermal.html | 열 설계와 접합 온도 — 손실이 열이 되는 길. 접합-케이스-냉각수 열저항, 포스터·카우어 열 회로와 과도 열 임피던스, 접합 온도 리플, 온도 의존 손실의 열 폭주, 냉각 방식. |
| 15 | chapters/packaging.html | 전력 모듈 패키징 — DBC·AMB 기판, 다이 접합과 은 소결, 와이어 본딩과 클립, 정류 루프 인덕턴스, 병렬 다이 전류 분배, 양면 냉각과 직접 냉각 모듈. |
| 16 | chapters/reliability.html | 신뢰성과 수명 — 파워 사이클링과 본드 와이어 들뜸, 코핀-맨슨 수명 모델과 누적 손상, 단락·애벌런치 견고성, 우주선 단일 사건 소손(FIT), HTRB·H3TRB, 미션 프로파일 수명 추정. |
| 17 | chapters/applications.html | 응용과 기술 선택 — 전기차 트랙션 인버터·OBC, 태양광·ESS, 데이터센터 전원, 고속 충전기, 철도·전력망. 사양에서 Si·SiC·GaN을 고르는 법, 비용과 시장, 다음 세대 소자. |
| 18 | chapters/glossary.html | 용어집 & 종합 퀴즈 — 전력 반도체 핵심 용어를 검색하고, 종합 퀴즈로 실력을 점검하자. |

공통 파일: `css/style.css`, `js/common.js`(전역 객체 `PW`, 레이아웃·시뮬레이터 헬퍼), `js/glossary-data.js`(용어집과 본문 툴팁이 함께 쓰는 용어 원본), `js/glossary-tooltips.js`. 집필 규칙과 PW-800 수치는 [CONTRIBUTING.md](CONTRIBUTING.md)에 있습니다.
