# ThinFilmBook — 인터랙티브 반도체 산화·박막 증착 교과서

원자 한 층씩, 막을 쌓는 기술. 8대 공정 학습을 심화하는 산화·박막 편으로, 공대 학부생과 신입 공정 엔지니어를 위한 한국어 학습 사이트입니다.
18개 챕터, 130여 개의 시뮬레이터, 3D 장비·구조 모델(three.js)로 구성되며, 가상 기준 장비 TF-300의 온도·압력·유량·펄스 조건으로 직접 막을 키워 봅니다.

배포 주소: https://semi.euiyun.com/thinfilm/

## 실행
원본은 빌드 없이 동작하는 정적 사이트입니다. 저장소 루트에서 실행하세요.

```bash
python3 -m http.server 8000   # → http://localhost:8000/thinfilm/
```
배포할 때는 저장소 루트의 `npm run build`가 head 메타데이터와 KaTeX 수식을 미리 렌더링합니다. three.js와 폰트는 CDN에서 불러오므로 인터넷 연결이 필요합니다.

| 03 | chapters/oxidation.html | 열산화와 딜-그로브 모델 — 산소가 산화막을 뚫고 들어가 계면에서 반응한다. 선형·포물선 성장, 건식과 습식, 면방위·압력·염소의 효과. |

| 05 | chapters/budget.html | 열 예산과 열처리 장비 — Dt로 재는 열 예산, 확산 길이와 램프의 기여, 배치 퍼니스와 RTP·스파이크·레이저 어닐, 온도 균일도와 슬립. |
| 06 | chapters/nucleation.html | 흡착·핵생성·성장 모드 — 흡착과 표면 확산, 고전 핵생성 이론, 섬 성장과 층 성장, 잠복기, 결정립과 구조 영역 모델. |

| 08 | chapters/sputter.html | PVD 심화: 반응성·이온화·응력 — 반응성 스퍼터링의 히스테리시스, 이온화 PVD와 재스퍼터, 롱스로·시준, 압력과 이온 충격이 만드는 막 응력. |
| 09 | chapters/cvd.html | CVD 반응과 수송 — 기상·표면 반응과 경계층 수송. 반응 제한과 수송 제한, 그로브 모델, 아레니우스 그림, 부착 계수와 반응 경로. |
| 10 | chapters/reactor.html | CVD 반응기와 PECVD — LPCVD 배치의 고갈, 샤워헤드와 체류 시간, PECVD의 저온 증착과 이온 충격, HDP-CVD 증착-식각 갭필, 에피 성장. |
| 11 | chapters/ald.html | ALD 반응과 포화 — 반쪽 반응의 자기 제한, 펄스·퍼지 사이클, 랭뮤어 흡착과 포화 곡선, 사이클당 성장, ALD 온도 창과 핵생성 지연. |
| 12 | chapters/aldadv.html | ALD 심화: 플라즈마·선택·고유전율 — PEALD의 래디컬 수명과 재결합, 공간 분할 ALD, 영역 선택 증착(ASD), 고유전율 HfO₂와 금속 ALD, 처리량 계산. |
| 13 | chapters/conformality.html | 피복성과 갭필 — 스텝 커버리지, 몬테카를로 입자 궤적, 크누센 확산과 고종횡비 노출량, 오버행·심·보이드, 증착-식각-증착. |
| 14 | chapters/uniformity.html | 균일도와 로딩 — 웨이퍼 안·웨이퍼 사이·배치 균일도, 온도와 유동장, 고갈과 패턴 로딩, 다구역 조절과 균일도 지표. |
| 15 | chapters/quality.html | 막질: 밀도·조성·응력·전기 특성 — 밀도와 굴절률, 수소와 불순물, 습식 식각률, 스토니 식과 응력, 누설 전류와 항복, 막질을 장비 조건으로 되짚기. |
| 16 | chapters/metrology.html | 박막 계측과 공정 제어 — 박막 간섭과 엘립소메트리, X선 반사율, 4탐침 면저항, 웨이퍼 휨, SPC와 런투런 제어. |
| 17 | chapters/integration.html | 응용과 통합: 게이트·배선·3D 낸드 — 게이트 스택, 스페이서와 라이너, 배리어·시드와 W 충전, 3D 낸드 ONO 적층과 하드마스크, 공정 비용으로 본 증착. |
| 18 | chapters/glossary.html | 용어집 & 종합 퀴즈 — 산화·박막 증착 핵심 용어를 검색하고, 종합 퀴즈로 실력을 점검하자. |

공통 코드: `css/style.css`(디자인 토큰, 라이트/다크), `js/common.js`(내비게이션, 캔버스·차트·3D 헬퍼, 전역 `TF`).
챕터 작성 규칙은 [CONTRIBUTING.md](CONTRIBUTING.md)를 참고하세요.

시뮬레이터의 수치는 교육용 근사 모델입니다. 실제 수치는 공개 자료 기준의 대략값이며 특정 회사의 내부 값이 아닙니다.

## 용어집과 본문 뜻풀이

용어 정의는 `js/glossary-data.js`의 `window.BOOK_GLOSSARY`에 저장합니다. 용어집과 본문 뜻풀이가 같은 데이터를 사용하며, 본문에서 용어에 마우스를 올리거나 키보드로 포커스하거나 모바일에서 탭하면 정의를 확인할 수 있습니다. 공통 동작과 스타일은 `js/glossary-tooltips.js`, `css/glossary-tooltips.css`입니다. 데이터 형식은 시리즈 공통 v1이며, 각 항목은 `ko`(이름), `en`(영문명), `abbr`(약어), `def`(정의), `chapters`(관련 장 목록)를 갖습니다.
